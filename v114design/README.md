# RIDER'S PAY floating UI redesign staging

This source branch stages the next floating-control design without replacing the currently signed public APK.

Design:
- smaller yellow sci-fi fare orb
- radial START / PICKED / WAIT / QR PAY controls around the orb
- smooth overshoot expansion and compact collapse
- haptic feedback on orb/actions
- user preferences: compact orb, haptic controls, auto-collapse
- dark glass QR panel with cyan/yellow accents

Public v1.1.3 remains the signed beta1-promoted build. Packaging this redesign as an in-place update requires the existing Rider Pay Personal Build signing key.
